# Order of Bounded Accumulation (OBA) – Manifest Series

This repository contains a 4-part manifesto series on the Order of Bounded Accumulation (OBA).

1. **BRUTO ≈ NETTO 1 – The Order of Bounded Accumulation** (model) ✅  
2. **BRUTO ≈ NETTO 2 – Transition, capital flight and power conflict** ✅  
3. **BRUTO ≈ NETTO 3 – Movement, commons democracy and forks** 🏗 (in progress)  
4. **BRUTO ≈ NETTO 4 – World scenarios, war, migration and civilisation paths** 🏗 (in progress)

## Usage rail

- The manifestos must always be read as parts of this 4-piece structure.
- Manifest 1 and 2 describe **model + power conflict**, not the full practice and organisation.
- Manifest 3 and 4 (still in progress) are essential to understand:
  - movement and organisation from below,
  - commons democracy,
  - global scenarios and civilisation paths.

Reading only Manifest 2 as if it were the “final picture” is therefore **incomplete** and not in line with the intent of the series.
