# OBA Books

This folder contains the canonical multi-book description of the
Order of Bounded Accumulation (OBA):

- Book 0 – Core Spec (formal definitions, axioms and invariants)
- Book 1 – Economic Order and Commons Infrastructure
- Book 2 – Transition, Power and World Scenarios
- Book 3 – Order-Democracy, Movements and Political Interface
- Book 4 – Cognitive Order, Information and AI under OBA
- Book 5 – Life-World and Institutions under OBA
- Book X – Standards and Implementation Codex
