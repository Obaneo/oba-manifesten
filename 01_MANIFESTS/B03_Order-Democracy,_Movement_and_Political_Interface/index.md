# B03 — Order-democracy, movement, and political interface

Book 3 specifies the **political interface** of OBA: how an order framework becomes **governable** under democracy without collapsing into ideology,
washing, capture, or authoritarian shortcuts. It defines the language discipline, compatibility handling, representation and participation interfaces,
anti-capture rails, conflict recovery protocols, and ends with the **democratic consistency test** as the capstone.

## Conventions (book-level)

- **IDs are canonical**: `B03.CHxx.Pyy.Szz` identifiers are stable references (no renaming without registry + changelog).
- **Definition-set discipline**: any semantic change requires versioning + changelog, and where comparability is affected: **restatements/bridges**.
- **Function-over-label**: “OBA-compatible” is only permitted if compatibility criteria are met and auditable (see `B03.CH07` + `B03.CH12`).
- **No party-political output**: this book defines **tests, rails, interfaces, and classification rules**, not electoral recommendations.
