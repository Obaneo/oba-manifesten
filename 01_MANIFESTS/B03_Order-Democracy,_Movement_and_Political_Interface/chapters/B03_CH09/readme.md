# B03.CH09 — Representation and participation: the role of citizens, workers, commons members, and the state

This chapter specifies **role-based representation and participation** as the mechanism that makes **order criteria governable**. It defines how
citizens, workers, commons members, intermediaries, and the state interact through **decision interfaces** that are compatible with OBA rails:
E-reduction, binding caps, stable R/B lower bounds, commons ΔG discipline, testable ΔM channels, and auditability.

The chapter is written to prevent a recurring failure mode: “participation” as a slogan that expands discretion and creates new capture surfaces.
Participation is treated as **authority + evidence + appeal rails**, not as performative consultation.

## How to use this chapter

- If you are **designing institutions**: use the role definitions and decision-domain separation to prevent capture and semantic blending.
- If you are **designing commons governance**: use commons membership rights/duties and multi-stakeholder boards with audit and appeal.
- If you are **writing mandates**: translate participation into testable procedures with hard stops, exception discipline, and re-authorisation.
- If you are **auditing legitimacy**: use the governance protocol requirements (decision logs, consultation handling, escalation, rollback).

## Status

This chapter is **normative** for OBA-compatible representation and participation design. It defines role structures, decision domains, procedural
guards, evidence and appeal rails, and failure-mode corrections. Any system claiming OBA compatibility must be able to map its participation model
to the interfaces and constraints specified here.
