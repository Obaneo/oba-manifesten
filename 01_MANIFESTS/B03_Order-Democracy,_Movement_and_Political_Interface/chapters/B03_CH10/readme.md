# B03.CH10 — Anti-capture mechanisms: lobbying, media, funding, and rotation systems

This chapter specifies **anti-capture** as mandatory infrastructure for OBA-compatible order-democracy. Capture is treated as an **endogenous drift
force**: it acts continuously on definition control, auditability, ΔM allocation, commons governance, and exception regimes. The chapter therefore
codifies a minimum set of constraints and protocols that make capture **detectable, costly, and reversible**, without collapsing pluralism or legitimate
interest representation.

Anti-capture here does not mean “ban interests.” It means: interests may exist, lobby, organise, publish, and fund—**only under disclosure,
contestability, auditability, rotation, and sanction rails** that prevent covert control over rules, measurement, and enforcement.

## How to use this chapter

- If you are **designing institutions**: implement the minimum anti-capture set (lobby registers, funding firewalls, revolving-door controls, rotation).
- If you are **writing mandates**: include capture indicators and escalation triggers as hard stops and periodic review obligations.
- If you are **building measurement/audit systems**: implement reproducibility, version pinning, and vendor exitability constraints.
- If you are **auditing order-democracy drift**: use the indicator set (institutional/economic/governance/narrative) and the intervention ladder.
