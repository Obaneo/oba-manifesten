# B03.CH10 — Anti-capture mechanisms: lobbying, media, funding, and rotation systems

This chapter specifies the **minimum anti-capture set** for OBA-compatible order-democracy. It treats capture as an **endogenous drift force** that
targets definition control, auditability, ΔM allocation, commons governance, and exception regimes. The chapter provides formal constraints for
lobbying and access, political and civil-society funding, revolving-door controls, media/narrative infrastructure, rotation and redundancy systems,
vendor lock-in prevention, definition/exception capture remedies, and a measurable indicator set linked to escalation and correction protocols.
