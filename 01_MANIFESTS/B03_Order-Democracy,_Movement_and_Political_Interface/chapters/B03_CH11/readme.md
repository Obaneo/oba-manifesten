# B03.CH11 — Conflict dynamics within OBA: internal schisms, splits, and recovery procedures

This chapter defines how **internal conflict** is handled inside **OBA-compatible order-democracy**. OBA deliberately binds extraction (caps), forces
transparent allocation (ΔM), and prioritises commons capacity (ΔG). Those constraints generate predictable internal tensions: distributional disputes,
scarcity conflicts, near-cap pressure, timing asymmetry, and audit/measurement controversies.

The purpose of this chapter is not to adjudicate ideology. It provides **conflict mechanics**, **diagnostic signatures**, and **recovery procedures**
that keep disagreements governable: evidence-bound, contestable, and reversible. It also defines when internal conflict crosses the line into a formal
**fork** with explicit naming and compatibility status (linking to B03.CH07).

## How to use this chapter

- If you are **designing governance**: implement the escalation architecture and hard stops to prevent sabotage and silent drift during conflict.
- If you are **operating commons/ΔM systems**: use the conflict-source typology to anticipate where disputes arise (allocation, access, caps pressure).
- If you are **auditing political integrity**: use the trigger patterns (exceptions↑, sanction rate↓, reproducibility↓, black-box allocation) to detect schism risk.
- If you are **managing movement cohesion**: distinguish parametric/interpretive conflict from existential rupture and route conflicts through protocols.
