# B03.CH12 — Closing: democratic consistency test and governance metrics

This closing chapter defines the **democratic consistency test** as the capstone of Book 3: a **pass/fail + escalation** mechanism that detects and
responds to **drift, capture, regression, and authoritarian overreach** inside OBA-compatible governance. The test evaluates governance integrity
through **fixed inputs**, **versioned definition sets**, **thresholds**, and a **response ladder** that is triggered by measurable signals.

The chapter is designed to be **machine-readable**: each metric has a definition, data sources, update cadence, thresholds, and linked interventions.
Its outputs are published as scorecards, incident reports, changelogs, and restatements, and it produces a formal **compatibility outcome** (compatible /
partially compatible / incompatible) with mandatory naming rules.
