# B03.CH12 — Closing: democratic consistency test and governance metrics

This closing chapter defines the **democratic consistency test** as the capstone of Book 3. Its function is to detect and respond to **drift, capture,
regression, and authoritarian overreach** inside OBA-compatible governance. The test is intentionally **pass/fail oriented** and is coupled to a
pre-committed **response ladder**: signals trigger enhanced audits, rollback and requalification, hard stops under black-box governance, governance reset,
and—where deviation is constitutive—re-authorisation and fork classification.

The test evaluates **governance integrity**, not sector-by-sector policy preferences. Its logic is that order-democracy remains legitimate only if it is
continuously **contestable**, **auditable**, and **definition-stable** while keeping exceptions bounded and reversible.

## How to use this chapter

- If you are **designing OBA governance**: implement the non-negotiables, metric definitions, thresholds, and response ladder as binding rails.
- If you are **auditing OBA compatibility**: run the scorecards, check threshold breaches, inspect incident logs, and verify restatement discipline.
- If you are **operating institutions**: use the early-warning set to trigger escalation before schism dynamics become irreversible.
- If you are **publishing public accountability**: use the output formats (consistency report, incident report, changelog, restatements) as mandatory artefacts.
