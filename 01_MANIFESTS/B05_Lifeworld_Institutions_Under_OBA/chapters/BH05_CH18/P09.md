# B05.CH18.P09 — Evasion: core logic (why it is systemic)

This paragraph specifies why **evasion** is systemic in lifeworld implementations. Evasion is not an anomaly; it is the predictable
response of strategic actors to constraints. When caps and rails change payoffs, actors search for new claim routes, new labels, new
channels, and new jurisdictions. CH18 treats evasion as an expected “adaptation war” requiring: (i) shift taxonomies, (ii)
substance-over-form logic, (iii) channel governance and leakage tests, and (iv) international no-arbitrage boundaries.

---

<a id="b05ch18p09s01"></a>
## B05.CH18.P09.S01 — Incentives shift: caps/rails change payoffs; actors search for new claim routes

### Core mechanism
Caps and rails compress old extraction routes. That makes previously marginal strategies valuable: complexity, restructuring, and
intermediation become payoff-maximizing. Evasion increases precisely when the system is effective against old routes.

### Canonical causal chain
`rail constrains old claim route`  
→ `expected profit from old route falls`  
→ `search for substitutes (new routes)`  
→ `innovation in contracts/channels/structures`  
→ `extraction returns unless detected and reclassified`

### Normative requirements (RFC 2119)
- Implementations **MUST** assume adversarial search as normal and maintain detection capacity accordingly.
- Anti-evasion is not optional “enforcement”; it is constitutive infrastructure for keeping the semantic core meaningful.

### Conformance tests (minimum)
- **EVA-LOG-01 (Assumption):** the implementation explicitly assumes adversarial adaptation and includes monitoring/updates.
- **EVA-LOG-02 (Capacity):** detection/audit capacity is treated as a maintained system (ΔG), not as a one-off project.

<a id="b05ch18p09s02"></a>
## B05.CH18.P09.S02 — Semantic arbitrage: new labels and contract forms attempt to bypass definitions

### Core mechanism
Semantic arbitrage is relabeling: changing terms and contract forms to move transactions outside a definition boundary while preserving
economic substance (control/benefit/block). It exploits any gap between text and enforcement.

### Canonical causal chain
`definition boundary declared`  
→ `actors relabel economic flows`  
→ `formal classification changes; substance unchanged`  
→ `cap/rail bypass appears “legal”`  
→ `system drifts unless substance-over-form is enforced`

### Normative requirements (RFC 2119)
- Semantic arbitrage **MUST** be countered by substance-over-form and look-through logic; labels cannot control classification.
- Definitions **MUST** be paired with evidence requirements and default presumptions under opacity (fail-closed against withholding).

### Conformance tests (minimum)
- **EVA-SEM-01 (Recharacterization):** the system includes reclassification rules for label shifts.
- **EVA-SEM-02 (Default presumptions):** missing evidence triggers conservative presumptions, not enforcement pause.

<a id="b05ch18p09s03"></a>
## B05.CH18.P09.S03 — Channel innovation: new rails (fintech/crypto), new intermediation, new bundles

### Core mechanism
Channel innovation changes *how* value moves: new payment rails, new intermediaries, new bundles and platforms. This can create shadow
channels and new toll layers that are not covered by existing controls.

### Canonical causal chain
`old channels governed/controlled`  
→ `new rails emerge (fintech/crypto/platform bundles)`  
→ `traceability declines; fee stacks move off-surface`  
→ `leakage into claims/fees rises`  
→ `shadow regime grows unless channel governance adapts`

### Normative requirements (RFC 2119)
- New channels **MUST** be classified under channel governance (allowed/conditional/forbidden) with tagging and leakage tests.
- Channel controls **MUST** be rail-level where possible; entity-by-entity enforcement alone is too slow.

### Conformance tests (minimum)
- **EVA-CHN-01 (Channel classification):** new rails are mapped to channel objects with conditions/forbidden flags.
- **EVA-CHN-02 (Leakage tests):** leakage tests exist for fee stacks and off-rail transfers.

<a id="b05ch18p09s04"></a>
## B05.CH18.P09.S04 — International arbitrage: treaty mismatch, re-domiciliation, transfer pricing, IP structures

### Core mechanism
International arbitrage exploits jurisdictional mismatches: treaties, residence rules, and corporate structures. It converts domestic caps
into optional constraints by moving control centers, assets, or profit attribution offshore.

### Canonical causal chain
`domestic rail imposes constraint`  
→ `actors re-domicile entities/control centers OR shift profits via transfer pricing/IP`  
→ `treaty benefits claimed; withholding avoided`  
→ `caps/rails bypassed`  
→ `system loses enforceability unless no-arbitrage and denial-of-benefits are applied`

### Normative requirements (RFC 2119)
- International arbitrage **MUST** be countered via look-through allocation, denial-of-benefits under insufficient substance, and
  withholding hooks under opacity/flight risk.
- Mobility remains possible, but **not as arbitrage** against core invariants (link CH16.P10).

### Conformance tests (minimum)
- **EVA-INT-01 (DoB):** denial-of-benefits logic exists and is operational.
- **EVA-INT-02 (Withholding readiness):** withholding hooks exist for leakage/mismatch conditions.
