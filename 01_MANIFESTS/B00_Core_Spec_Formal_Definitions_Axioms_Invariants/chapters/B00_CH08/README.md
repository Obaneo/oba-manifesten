# B00.CH08 — Definition set VI: monetary space as allocation interface (ΔM; channel rules; prohibited channels)

This chapter defines **Definition set VI**, which introduces **monetary space (ΔM)** as the allocation interface
within OBA, focusing on how **monetary flows** (ΔM) are managed through regulated channels, and the rules governing
these flows. It describes the conditions under which **capital allocation** can occur, as well as the necessary rules
and conditions that ensure these flows are non-extractive, fair, and contribute to overall **R/B stability** (life-world
buffers).

The chapter also outlines the **prohibited channels** (e.g., asset inflation, rent-seeking, or untraceable intermediaries)
and the **priority rules** for the allocation of funds within commons, emphasizing a **maintenance-first** approach and
**crisis-regime protocols** for exceptional circumstances.

## How to use this chapter

- If you are **writing any later chapter**: Import **ΔM** definitions, channel rules, and **prohibited channel**
  criteria from here; do not redefine them locally.
- If you are **designing financial models or allocation strategies**: Apply the **ΔM framework** and ensure that your
  allocation adheres to the priorities (e.g., maintenance, R/B stabilisation, productive credit).
- If you are **monitoring compliance**: Ensure that any monetary allocation or financing of public goods is **traceable**,
  **auditable**, and **non-extractive** in accordance with the defined **channel rules**.

## Status

This chapter provides the **normative foundation** for **monetary space (ΔM)** as an allocation interface within OBA
and governs the key rules for managing monetary flows, ensuring they contribute to social stability, public goods
provision, and life-world buffering. This chapter must remain stable across versions, as changes here have significant
impacts on the financial architecture of OBA systems.

If changes occur, they must be aligned with strict monitoring rules, keeping non-extractive flow principles intact. Non-compliance
with ΔM allocation rules or prohibited channels will result in failure to meet OBA standards.
